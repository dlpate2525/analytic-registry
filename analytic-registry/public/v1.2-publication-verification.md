# V1.2 publication verification

Application `1.2.0-prototype.1`, workbook revision `1.2`, input schema `1.1`. Reviewed 21 October 2026.

## Evidence boundary

The React application uses fictional records, simulated profiles, and local browser storage. Browser checks use isolated contexts at 1366 × 768. They do not change the user's saved browser data.

Query fixtures execute current projections using documented SQLite substitutions. Static checks verify query output headers and guarded mappings. Neither method proves execution on SQL Server, Tableau, Alteryx, or Fabric installations.

The spreadsheet runtime exported the revised workbook, then reported a Windows native shutdown error. Independent OOXML checks inspect the saved file. Microsoft Excel and Power Apps import remain untested.

## Release corrections

- Unavailable Asset references retain their IDs and explain why navigation is absent.
- Workspace requests retain a nonblocking backup warning when only one Champion is selected.
- Power BI scan-output coverage counts use the actual emitted projections.
- Alteryx SID-only members retain distinct unresolved raw references. Namespace checks prevent false Gallery resolution.
- Preparation uses current release metadata and exact source, archive, public, and build checksums.
- Current documentation links use the V1.2 workbook. Historical documents retain their original scope.

## Review stages

Architect and Arena compared two release designs. Independent agents using the same model reviewed both. The chosen design retains one metadata authority and verifies current artifact copies.

Test-first repairs cover unavailable Asset navigation, the one-Champion warning, emitted coverage counts, and Alteryx identity namespaces. TypeScript, Deslop, and No Comments reviews removed redundant material while retaining evidence and compatibility explanations.

Blast Radius and the strict code-quality review tested cross-module authority and preservation. One optional helper reuse was deferred because its current module re-export would introduce a circular dependency. No executable source file crosses 1,000 lines. The JSON contract is a larger data document.

The verification skill covers five isolated browser journeys. Swarm partitions independent review and verification. Interrogate reviews the exact candidate through two independent agents using the same model. The PR records their verdicts separately from author checks.

Make PR Easy to Review provides the review map. Babysit checks conflicts, review comments, and CI before merge. Get PR Comments records actionable feedback. Fix Merge Conflicts applies only if a real conflict exists. Benchmark Checklist has no speed claim to assess.

The host uses GitHub connector operations instead of unavailable `gh` and Origin commands. Independent local browser verification replaces the unavailable Cursor cloud-agent lane. These are disclosed adaptations, not claims that unavailable services ran.
