## Query revision 2 review

Alteryx now uses SQL Server copies of Gallery and Service through documented mapping views. Tableau adds ordinary PostgreSQL SELECT batches. Fabric adds a landed-inventory SQL projection and DAX discovery. The app, workbook, dictionary, and handoff use the same query references.

Independent review repaired NULL coverage counts, manifest truncation, malformed UUID acceptance, missing timestamp offsets, oversized values, padded IDs, and nullable verification flags. Fabric validates and reads within a transaction. Alteryx requires one verified immutable source snapshot. No native identity namespace or input header changed.

The workbook generator saved the file but returned a nonzero process status after export. The saved XLSX passed independent ZIP/XML checks and all 4,729 exact reference-cell comparisons. Native Excel behavior was not tested.

## Repaired behavior

- Older, rejected, or historical-version assessments cannot replace current approved classifications.
- New approved PRL records require an approver and reference, with no calculated score.
- Draft, annual response, and assessment commands bind attribution to the current prototype actor.
- New approval receipts capture eligibility evidence. Later account changes do not rewrite historical decisions.
- Current Champions use the implemented baseline. Annual packets preserve frozen recipients, including empty lists.
- Pending requests do not hide observed drift. Group additions and removals affect approval requirements.
- Duplicate group names are blocked. In-progress annual work becomes overdue after its deadline.
- Closing evidence enters the approval queue. Delivered new workspaces remain visible until linked to a registry record.
- Duplicate directory evidence remains unresolved. Non-person principals do not become Person records. Disabled and unknown states remain distinct.
- Monthly comparison preserves native identity across renames and flags older or conflicting same-time observations.
