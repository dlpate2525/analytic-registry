# V1.2 publication

The V1.2 prototype uses application version `1.2.0-prototype.1`, workbook revision `1.2`, and input schema `1.1`.

See [the release record](analytic-registry/docs/v1.2-release.md), [verification](analytic-registry/docs/v1.2-publication-verification.md), and [manifest](V1.2-BASELINE.json).

Preparation creates local artifacts. GitHub publication is a separate operation. The [V1.2 GitHub release](https://github.com/dlpate2525/analytic-registry/releases/tag/v1.2.0-prototype.1) is the publication receipt once created. It identifies the merged tag and links the reviewed PR and validation results. Local preparation alone does not establish publication.

Historical manifests describe their original tags. They are not checksums for current files.
